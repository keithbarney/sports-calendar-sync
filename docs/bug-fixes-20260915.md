# Bug fixes reviewed 2026-09-15

This change keeps Debug mock and screenshot review state separate from the normal app preference domain, reconciles reminder changes against existing app-owned calendar events and pending notifications, adds boundary and failure review scenarios, and enables the existing background refresh lifecycle when iOS permits it.

Changed files:

- `SportsCalendarSync/Services/AppSettings.swift` — isolated mock/capture appearance and reminder preferences in `SportsCalendarSync.mock.preferences` and kept normal launches on `UserDefaults.standard`.
- `SportsCalendarSync/Services/SyncHealthStore.swift` — uses the same isolated preference store by default so mock diagnostics do not clear or overwrite personal sync state.
- `SportsCalendarSync/Services/AutomaticRefreshService.swift` — enabled registration/scheduling, blocked BGTask registration for mock/capture runs, isolated the metadata-repair marker, and refuses cancelled background tasks before starting work.
- `SportsCalendarSync/Services/CalendarService.swift` — added the calendar scheduling seam used by reconciliation tests.
- `SportsCalendarSync/Services/NotificationService.swift` — added asynchronous app-owned notification reconciliation with completion error reporting and ordered all app-owned mutations so Off/removal cannot be undone by an earlier add that completes late.
- `SportsCalendarSync/Services/TeamManager.swift` — reads the isolated reminder store, serializes/coalesces overlapping preference reconciliations, and rewrites every stored fixture's EventKit alarm and pending notification without fetching ESPN. Cancelled and postponed fixtures keep their notification removed.
- `SportsCalendarSync/Views/ProfileView.swift` — immediately starts reconciliation when the Reminder picker changes and shows success/failure guidance.
- `SportsCalendarSync/Services/ScreenshotFixtures.swift`, `SportsCalendarSync/SportsCalendarSyncApp.swift`, `SportsCalendarSync/Views/MockReviewView.swift` — added Dates pending, Sync failure, and Long titles scenarios with independent in-memory stores.
- `SportsCalendarSyncTests/BackgroundRefreshSchedulingTests.swift`, `SportsCalendarSyncTests/RefreshPolicyTests.swift`, `SportsCalendarSyncTests/ScreenshotFixturesTests.swift` — preference isolation, reminder Off/failure seams, review scenario, and background registration coverage.
- `SportsCalendarSyncScreenshotTests/CaptureTests.swift` — native iPhone/iPad review route for scenario switching and Reminder Off.

- The pre-existing `CaptureTests.testCaptureAllScreens` retained-navigation-stack failure remains outside this fix; it is not caused by the reminder/scenario changes.
